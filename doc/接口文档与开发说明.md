# 接口文档与开发说明

面向 **admin-layui** 后台脚手架：同域 Thymeleaf + Layui/Pear，后端包名 `com.ylmao.admin`，Sa-Token 鉴权，MyBatis-Plus 访问 MySQL，Redis 承载会话与缓存。

| 资源 | 说明 |
| --- | --- |
| 数据库种子 | `doc/admin-layui.sql` |
| 前端组件 | **Layui 2.13.9**（`static/component/layui`）、[官方文档](https://layui.dev/)；页面样板见 `templates/system/user.html`、`role.html` |

本文只摘 **接口与联调** 必需约定；URL/PO/DTO 等完整规范见本文第 5 节及仓库内 `user` / `role` / `post` 样板代码。

后台文档页为 iframe 嵌入 Swagger UI；若当前环境关闭了 springdoc，页面会提示查看本文。

### Swagger 分组（`OpenApiConfig`）

| 分组 id | 显示名 | 扫描范围 |
| --- | --- | --- |
| `system` | 系统模块 | `com.ylmao.admin.controller.system` |
| `admin` | 后台框架 | `com.ylmao.admin.controller.admin` |
| `root` | 登录与其它 | `com.ylmao.admin.controller` 下 `/login`、`/captcha/**`、`/home/**`、`/upload/**` |

仅收录带 `@ResponseBody` / `@RestController` 的 **JSON 接口**；`listView` 等页面跳转不出现文档中。

### 为新模块补充文档注解

对照 **`PostController`**（`@Tag` + 各 JSON 方法上的 `@Operation`）：

- 类上 `@Tag(name = "…", description = "…")`
- 列表/增删改/唯一校验/启停等 JSON 接口加 `@Operation(summary = "…")`
- 页面跳转方法 **不要** 加 `@Operation`（避免混入 API 文档）

## 1. 鉴权

| 项 | 说明 |
| --- | --- |
| 登录 | `POST /login`（账号、密码、验证码）；成功写入 Cookie **`saToken`** |
| 同域后台 | 浏览器自动带 Cookie；Thymeleaf 页面与同域 Ajax 均依赖 Cookie |
| 脚本 / 跨域 | 请求头 **`saToken: <token>`**（与 Cookie 同名）；CORS 白名单见 `SaTokenConfigure` |
| 权限 | `@SaCheckPermission("模块:资源:动作")`；权限码与 `sys_perm.perm_code`、菜单种子一致 |
| 未登录 | Ajax 业务码 `401`；页面跳转登录 |
| 无权限 | Ajax `403` |

调试 Swagger：先浏览器登录后台，再打开文档页；可在 **Authorize** 中填写请求头 `saToken`（与 Cookie 二选一即可同域场景）。

## 2. 统一返回与异常

JSON 响应体为 **`com.ylmao.admin.common.R`**：

| 字段 | 含义 |
| --- | --- |
| `code` | `200` 成功；业务失败常见 `500`；鉴权 `401` / `403` |
| `msg` | 提示文案 |
| `data` | 载荷；无数据可为 `null` |
| `count` | 仅分页列表：总条数（Layui table） |

成功：`R.ok()` / `R.ok(data)` / `R.page(list, total)`；Controller 可用 `BaseController` 的 `pageData(data, count)`。  
业务失败在 Service 抛 **`BusinessException`**，由全局异常处理写成 `R.fail(...)`。  
基础校验放在 DTO（`@Valid`）；Controller 不重复做字段级与业务规则校验。

---

## 3. 分页

列表接口使用 **`PageQuery`**：

- `page`：页码，默认 `1`
- `limit`：每页条数，默认 `10`，最大 `100`

典型链路：`PageQuery` + 模块 `XxxList` DTO → Service `selectPage` → `pageData(records, total)`。

## 4. 前端 Ajax 约定

- 全局前缀：`window.apiPath`（布局页注入）
- 增删改：`postJson` / `putJson` / `patchJson` / `deleteJson`（`static/component/pear/module/common.js`）
- 提交 JSON：`contentType: 'application/json'`，`data: JSON.stringify(...)`
- 错误：优先 **`getAjaxErrorMsg(xhr, '默认文案')`**，展示后端 `msg`
- 表格：`TABLE_RESPONSE`，与 `R` 的 `code` / `data` / `count` 对齐
- 调用后端 API 的脚本前加一行简短注释（列表、唯一校验、保存、启停、删除等）

HTTP 动词：新增 **`POST`**，修改 **`PUT`**，启停 **`PATCH`**，删除 **`DELETE`**。

## 5. 模块开发规范（标准 CRUD）

1. **对照样板**：主参考 **`user`**，次参考 **`role`** / **`post`**（岗位含 OpenAPI 样板注解）。
2. **URL**：类上 `@RequestMapping("/模块")`，方法上只用动作（`/listView`、`/list`、`/add`、`/update`、`/delete`、`/updateEnabled`、`/checkName`…），**禁止**重复模块词（如 `/post/postList`）。
3. **Java 方法名**：可带模块前缀（如 `postList`）；与 URL 动作分离，见本文与 `user` / `role` 模块。
4. **分层**：Controller 只收 DTO、调 Service、返回 `R`；业务规则与唯一性等在 Service，失败抛 `BusinessException`。
5. **DTO / VO / PO**：增删改各用 `XxxInsert` / `XxxUpdate` record；列表返回 VO，不以 PO 作为请求体。
6. **权限与菜单**：改 `sys_perm.perm_url`、`perm_code` 时同步 Controller、前端、`doc/admin-layui.sql`（或迁移 SQL）。
7. **代码生成**：开发工具 → 代码生成 → 下载 ZIP → 解压到项目根 → 合并代码 → 执行包内 `sql/*_perm.sql`；生成 Java 路径为 `com/ylmao/admin/...`。

验收：按本文 + 生成器（或抄 `post`）完成列表 / 增 / 改 / 删 / 启停，并在 Swagger **system** 分组中看到对应 JSON 接口。

## 7. 本地运行与常见问题

| 项 | 说明 |
| --- | --- |
| Profile | 默认 **dev**（`application.yml` 中 `spring.profiles.default`）；生产加 `--spring.profiles.active=prod` |
| 端口 | dev 默认 **8085**（见 `application-dev.yml`） |
| MySQL / Redis | 连接信息在对应 profile 的 yml 中配置；导入 **`doc/admin-layui.sql`** 初始化库表与种子 |
| 启动校验 | `SecurityConfigChecker` 要求 `sys_config` 中存在完整的 **`security.*`** 七项（含 `security.autoBanMin`）；缺项会启动失败 |
| 包名 / 类名变更后登录报错 | Redis 中旧 Sa-Token 会话可能仍序列化旧类名（如 `com.md.admin.entity.User`）；开发环境可 **`FLUSHDB`** 或删除 satoken 相关 key 后重新登录 |

更完整的安装、部署与 Nginx 示例见仓库根 **`README.md`**、`doc/nginx-admin.example.conf`。
